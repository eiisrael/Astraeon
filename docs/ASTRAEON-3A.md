# ASTRAEON 3.0-A — Hardcore UI

Esta fase inaugura a direção visual dark-fantasy do Astraeon sem substituir o mundo procedural e o gameplay-base 2.x.

## Entregas
- visual hardcore compacto para menu, HUD, inventário, mapa, ajuda e pausa
- imagens vetoriais originais para itens, geradas pelo próprio runtime
- 20 novas peças exclusivas de classe
- restrição real de equipamentos por classe
- loot priorizando itens compatíveis com a classe atual
- mochila/equipamento/Item List reorganizados para desktop e mobile
- tabs mobile para equipamento, mochila e Item List
- controles touch de movimento, ataque e habilidades
- configurações persistentes: escala da UI, clima, dano flutuante, minimapa, modo compacto, touch e tela cheia

## Compatibilidade
A fase mantém saves 2.1, migra a apresentação dos itens existentes e preserva os módulos `world-v2.js`, `game-v2.js` e `inventory-v2.js` como base estável.
