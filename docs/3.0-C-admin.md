# Astraeon 3.0-C — Admin & Typography

## Admin Console
Abra `game-editor.html` e clique em **Admin 3.0-C** ou pressione `F10`.

A Console Admin possui páginas para Personagem, Gameplay, Classes, Mobs, Itens, Biomas e edição JSON avançada de Admin/save/mundo.

## Runtime
As configurações são salvas em `localStorage` usando `astraeon:v3c:admin` e aplicadas ao jogo pelo módulo `src/admin-runtime-v3c.js`.

## Tipografia
`src/typography-v3c.css` usa escalas responsivas com `clamp()` para desktop e mobile, evitando os rótulos de 6–9 px das versões anteriores.

## Editor de Painéis 8.0

No Admin Studio, abra **Administração → Editor de Painéis**. A biblioteca reconhece os 15 painéis nativos do jogo e também permite criar painéis personalizados.

O projeto visual é persistido em `localStorage` com a chave `astraeon:v7:panel-studio` e esquema de documento v2. O módulo `src/panel-studio-runtime-v7.js` aplica as alterações publicadas automaticamente no jogo. Painéis personalizados também podem ser controlados pela API `window.AstraeonPanelStudio` (`open`, `close` e `toggle`) ou pelo atalho definido no inspetor.

Ferramentas disponíveis:

- preview real do painel dentro do jogo e seleção direta no canvas;
- árvore de camadas com todos os textos, botões, grids, imagens e contêineres reais;
- criação, duplicação, ocultação reversível e remoção de elementos;
- conteúdo, tipografia, imagens locais ou remotas por painel ou por camada;
- dimensões, posição, camada Z, ordem, padding, margem, bordas e opacidade;
- edição de Grid/Flex, colunas, linhas, células, espaçamento e alinhamento;
- vértices independentes, rotação, inclinação e escala;
- gradientes, filtros, desfoque, sombras, glow, brilho e saturação;
- presets, grade, snap, zoom e prévias desktop/tablet/mobile;
- histórico de 100 estados, duplicação, importação e exportação JSON.

Atalhos principais: `Ctrl+S` salvar/publicar, `Ctrl+Z` desfazer, `Ctrl+Y` refazer, `Ctrl+D` duplicar a seleção, `Ctrl+N` adicionar texto, `Ctrl+Shift+C/V` copiar/colar estilo, `Ctrl++/-/0` controlar o zoom, `Delete` excluir ou ocultar e setas para mover a seleção (`Shift` move 10 px).

Botões genéricos não são mais criados automaticamente. O texto **Continuar** permanece apenas no painel de Pausa, onde corresponde ao botão real `#resumeBtn`; nos demais painéis, botões aparecem somente quando já existem no jogo ou quando são adicionados explicitamente pelo editor.
